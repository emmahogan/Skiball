## Git Commands

### Branching

To view all available branches:

```
git branch
```

To create a new branch (replace 'branch-name' with specified name):

```
git branch branch-name
```

To switch to a branch (replace 'branch-name' with name of branch you want to switch to):

```
git checkout branch-name
```
